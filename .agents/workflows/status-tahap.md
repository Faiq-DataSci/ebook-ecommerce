# Workflow: Cek Status Tahap Proyek

1. Baca `docs/docs-proyek-ebook-ecommerce.md` dan `docs/00-project/project-plan.md` serta `docs/00-project/keputusan-terbuka.md`.
2. Periksa keberadaan file dan implementasi aktual di `backend/`, `admin-web/`, `mobile/`, dan `docs/`.
3. Periksa apakah terdapat tes yang sudah berjalan untuk masing-masing lapisan.
4. Laporkan status tiap tahap secara jujur menggunakan salah satu label:
   - **Belum dimulai**
   - **Sedang dikerjakan**
   - **Selesai** (wajib disertai bukti file dan hasil tes yang dijalankan)
   - **Terhambat** (wajib disertai penyebab atau keputusan terbuka yang memblokir)
